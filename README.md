# AdVeil

> Mute and blur ads on JioHotstar for a cleaner cricket experience.

AdVeil browser extension is designed for cricket fans who stream matches on JioHotstar. It lets you focus fully on the game by automatically muting and blurring ad breaks, providing a cleaner, more enjoyable cricket experience. You can change the blur intensity via the extension's popup panel in the toolbar. All settings are stored locally in the browser, thus ensuring your preferences persist across sessions without sending any data out of your device. AdVeil is built to avoid interference with the actual match content. When advertisements end, AdVeil restores the original audio and video quality, ensuring a smooth transition back to gameplay.

### Privacy

No personal data is collected. AdVeil extension does not send any data out of your device. User settings are stored locally in the browser storage.
